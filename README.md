# CI/CD Practice with GitHub Actions

This repository is created to learn and practice CI/CD concepts using GitHub Actions.

## About This Project

The main goal of this project is to understand how Continuous Integration (CI) works and how to automate development workflows using GitHub Actions.

## What I Am Learning

- GitHub Actions fundamentals
- Workflows, Events, Jobs, and Steps
- Runners and Actions
- Running Linux commands
- Python environment setup
- Installing project dependencies
- Running automated tests with Pytest
- Building Docker images
- CI/CD pipeline automation
